# Vinayaka Portfolio

## Files
- `index.html` — portfolio structure and updated resume content
- `style.css` — responsive modern UI
- `script.js` — navigation, reveal animation, scroll progress and back-to-top
- `assets/profile.jpg` — add your actual photo here
- `assets/profile-placeholder.svg` — automatic fallback if profile.jpg is missing

## Add your actual photo
Put your photo in the `assets` folder and name it exactly:

profile.jpg

Recommended: a clear square portrait, preferably 800x800 or larger.

## Links
LinkedIn and GitHub are included from the older portfolio information. The LeetCode button currently opens the LeetCode homepage because a verified personal LeetCode profile URL was not present in the supplied CV.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.
